## 推导

### 目标

已知躯干姿态四元数 $q = (w, x, y, z)$，求重力方向 $[0, 0, -1]$ 在躯干坐标系下的表示。

### 方法：四元数旋转向量

用四元数把一个向量从世界系变到躯干系，公式是：

$$\mathbf{v}' = q^{-1} \otimes (0, \mathbf{v}) \otimes q$$

其中 $q^{-1} = (w, -x, -y, -z)$（单位四元数的逆等于共轭）。这里 $q$ 是"躯干→世界"的旋转，$q^{-1}$ 就是"世界→躯干"。

### 代入 $\mathbf{v} = [0, 0, -1]$

纯四元数 $(0, 0, 0, -1)$，先算 $q^{-1} \otimes (0, 0, 0, -1)$：

用四元数乘法 $(w_a, x_a, y_a, z_a) \otimes (w_b, x_b, y_b, z_b)$ 的公式，$(w, -x, -y, -z) \otimes (0, 0, 0, -1)$：

$$w_a = w,\ x_a = -x,\ y_a = -y,\ z_a = -z$$
$$w_b = 0,\ x_b = 0,\ y_b = 0,\ z_b = -1$$

$$\text{中间结果} = (x,\ -y,\ w,\ -z \cdot(-z) \cdot... )$$

展开太长，直接用已化简的结果。$q^{-1} \otimes (0, 0, 0, -1) = (y,\ -x,\ -w,\ -z)$，再右乘 $q$：

$$(y,\ -x,\ -w,\ -z) \otimes (w, x, y, z)$$

展开四元数乘法的四个分量：

$$w' = y \cdot w - (-x) \cdot x - (-w) \cdot y - (-z) \cdot z = 0$$

$$x' = y \cdot x + (-x) \cdot w + (-w) \cdot z - (-z) \cdot y = 2(xz - wy) \cdot (-1)$$

整理后三个分量（标量部分 $w' = 0$，符合预期——旋转向量结果还是纯向量）：

$$g_x = -2(xz - wy)$$
$$g_y = -2(yz + wx)$$
$$g_z = -(1 - 2(x^2 + y^2))$$

### 验证：直立时 $q = (1, 0, 0, 0)$

$$g_x = -2(0 - 0) = 0$$
$$g_y = -2(0 + 0) = 0$$
$$g_z = -(1 - 0) = -1$$

$$\mathbf{g} = (0, 0, -1) \quad \checkmark$$

### 验证：绕 Y 轴转 90°（MOUNT 校正后的情况）

$q = (\sqrt{0.5}, 0, \sqrt{0.5}, 0)$：

$$g_x = -2(0 - \sqrt{0.5} \cdot \sqrt{0.5}) = -2 \cdot (-0.5) = 1$$
$$g_y = -2(0 + 0) = 0$$
$$g_z = -(1 - 2(0 + 0.5)) = -(1 - 1) = 0$$

$$\mathbf{g} = (1, 0, 0)$$

重力指向躯干 +X，说明机器人"水平躺着、头朝前"——和绕 Y 轴转 90° 一致。

### $g_z$ 分量的直觉

$g_z = -(1 - 2(x^2 + y^2))$。当 $x^2 + y^2 = 0$（没有绕 X/Y 的倾斜），$g_z = -1$（直立）。当 $x^2 + y^2 = 0.5$（倾斜 90°），$g_z = 0$（躺平）。当 $x^2 + y^2 = 1$（倒立 180°），$g_z = +1$。
