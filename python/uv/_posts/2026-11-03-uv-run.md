`uv run` 自带 install 这一步。在项目目录里运行时，它会先自动做一次 `uv sync`，再执行命令：

1. 按 `uv.lock` 创建或更新 `.venv`，装好依赖。
2. 以 **editable** 方式安装项目本身（前提是 `pyproject.toml` 里有 `[build-system]`）。
3. 安装项目时，`[project.scripts]` 里的每一项会生成 `.venv/bin/<name>` 可执行文件（Windows 上是 `.venv\Scripts\<name>.exe`）。
4. 把 `.venv/bin` 放到 `PATH` 最前面，再执行`<name>`

**补充**：

- **改代码不用重装**：项目是 editable 安装，改 `.py` 立刻生效。
- **改 `pyproject.toml` 也不用手动处理**：比如新增或修改一个 script，`uv run` 会发现文件变了，自动重新 sync。
- **没有 `[build-system]` 就不会生成 scripts**：项目不会被安装，`[project.scripts]` 也不会生成命令，uv 会给出警告。
- **`--no-sync` 会跳过第一步**：`uv run --no-sync <name>` 只用 venv 现有的内容。
- **想确认实际跑的是哪个**：运行 `uv run which <name>`（Windows 用 `uv run where <name>`），再看这个 shim 文件里 import 的是哪个模块。
