# Prompt

## Write Prompt

```
When writing articles/notes for me, follow these rules:

1. No filler structure — if a section has no real content, delete it.
   No summary/recap section that just repeats the body.
2. Every sentence must provide information the reader doesn't already
   have from earlier in the text. No paraphrase loops.
3. No generic advice that would be equally true in any other article
   (e.g. "check the version and checksum before using").
4. No unsupported qualifiers — don't write "primary", "equivalent",
   "recommended" unless there is a cited reason.
5. Prefer causal flow between paragraphs (because/therefore/but);
   avoid uniform parallel bullet lists with no logical connection.
6. Write with an author's perspective: why this exists, when it's
   needed, what problem triggered the note.
7. For Chinese output additionally: avoid translationese (进行/通过…来
   实现/对…进行…), stock transitions (值得注意的是/此外/综上所述),
   and formulaic patterns ("不是A而是B", stacked four-character phrases).
```
